FootStep

Automatiza los pedidos de tu restaurante

Sin apps. Sin comisiones. Sin una persona pegada al telefono.

El Problema

En ciudades pequenas e intermedias, los restaurantes gestionan pedidos por WhatsApp o Telegram de forma manual.

  • Una persona dedicada a leer mensajes y transcribir pedidos
  • Errores al anotar direcciones, productos o precios
  • Sin visibilidad en tiempo real para la cocina
  • Sin historial organizado de pedidos
  • Cero presencia digital (sin pagina web, sin menu online)

La Solucion

FootStep le da a cada restaurante un enlace unico con su menu digital. El cliente pide desde el celular, el restaurante recibe el pedido al instante.

Panel de Administracion

El dueno del restaurante configura todo desde un solo lugar:

Perfil y Marca

Logo, banner, colores personalizados, direccion y telefono. Cada restaurante tiene su identidad visual.

Menu Completo

Categorias, productos con fotos, precios, toppings opcionales y etiquetas destacadas.

Metodos de Pago

Efectivo, transferencia bancaria o Bre-b. Configurable por restaurante.

Historial de Pedidos

Consulta todos los pedidos con filtros por estado y fecha. Detalle completo de cada orden.

Experiencia del Cliente

Sin descargar apps. Sin crear cuenta. Solo abrir un enlace.

  • Menu visual con fotos, precios y descripciones
  • Carrito de compras con toppings y notas especiales
  • Seleccion de entrega: domicilio, recoger o comer en el local
  • Formulario de direccion adaptado a Colombia
  • Seleccion de metodo de pago con calculo automatico
  • Confirmacion con numero de referencia para seguimiento

Notificaciones y Panel de Cocina

Telegram Automatico

Cada pedido nuevo genera una notificacion instantanea en Telegram con todos los detalles: productos, direccion, metodo de pago y total. Reemplaza a la persona que antes leia mensajes.

Panel de Cocina (tiempo real)

Pantalla para el chef con pedidos activos ordenados por llegada. Estados con colores: recibido, confirmado, en preparacion, completado. Actualizacion via WebSocket sin refrescar.

Arquitectura Tecnica

Monolito modular. Simple de desplegar, facil de mantener.

Astro SSR + React Islands (frontend) | | HTTPS (REST + WebSocket) v Django REST Framework (backend) | URL -> View -> Service -> Model -> DB | S3 (imagenes) + Redis (real-time) | v PostgreSQL (AWS RDS)

Stack Tecnologico

Tecnologias modernas, probadas y de bajo costo operativo:

Django 5.2 PostgreSQL 16 Astro 7 React Docker AWS S3 Redis Django Channels JWT Auth Telegram Bot API WebSocket TypeScript
  • Autenticacion JWT para duenos, sin auth para clientes
  • Imagenes subidas directamente a S3 via boto3
  • WebSocket (Django Channels + Redis) para panel de cocina
  • Contenedores Docker para desarrollo y despliegue

Por que FootStep

Sin comisiones por pedido

A diferencia de Rappi o iFood, no cobramos porcentaje por cada venta. El restaurante mantiene el 100% de sus ingresos.

Sin friccion para el cliente

No necesita descargar app ni crear cuenta. Abre el link y pide. Funciona en cualquier celular con navegador.

Marca propia del restaurante

Colores, logo y banner propios. No es una plataforma generica donde el restaurante se pierde entre miles.

Pensado para ciudades intermedias

Diseado para restaurantes que hoy no tienen presencia digital. Simple, accesible y con soporte para pagos locales (efectivo, Bre-b).
