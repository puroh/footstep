# Code Language Convention

All source code in this repository MUST be written in English:

- **Variable names**: English (e.g., `order_items`, `delivery_fee`, `restaurant_slug`)
- **Function/method names**: English (e.g., `create_order`, `validate_session`, `get_menu`)
- **Class names**: English (e.g., `Restaurant`, `OrderItem`, `NotificationBackend`)
- **URL paths**: English (e.g., `/api/v1/menu/`, `/api/v1/orders/`, `/ws/kitchen/`)
- **Constants and enums**: English (e.g., `DELIVERY_TYPES`, `ORDER_STATUS`)
- **Comments**: English
- **Commit messages**: English
- **Database table and column names**: English
- **API field names in JSON**: English (e.g., `delivery_type`, `special_instructions`)

## Exceptions

- User-facing text (UI labels, error messages shown to end users) can be in Spanish since the product targets Colombian restaurants.
- Documentation files (PROGRESS.md, ARCHITECTURE.md, specs) can be in Spanish.
- Git branch descriptions can reference Spanish feature names if needed.
